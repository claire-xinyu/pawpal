# PawPal V3.2 产品体验

## 信息优先级

|页面|打开的原因|先看什么|下一步|
|---|---|---|---|
|我的家|照顾家里的伙伴，留下今天|宠物照片、今日事项与状态|完成照护、上传、打开某宠物趋势|
|健康|了解现在与近期变化|当日进食/饮水/如厕与最近体重|选择指标/范围、追溯事件、修正归属或记下观察|
|成长|寻找、回看和留下照片|按拍摄时间组织的摄影内容|宠物/年份/月/文字查找，连续翻看，编辑或分享|
|发现|看看其他宠物，探索养宠生活|照片与任务场景|摸摸头、下一只、筛选内容、进入同城路线/生活/求助|

首屏不再介绍产品理念。家庭名称、成员、提醒与空间入口在顶部；来源与技术能力集中在空间说明及账户中。来源不被隐藏：设备显示「已连接 · 模拟」，社区使用简洁的「体验内容 / 体验分享」标记，传播影响发生前明确确认仅浏览器可见。

## 空间与数据边界

体验模式提供耳朵和尾巴的家：真实资料和经筛选相册，另有明确模拟的三台设备、90天生活事件与两项预置照护。没有虚构真实称重、疫苗、驱虫、治疗或家庭成员活动。

我的空间是空家庭、当前操作者和自行创建的宠物。设备始终未连接；不会继承双猫相册、虚拟设备或医疗记录。两种模式的元数据分别保存，模式切换可逆，不重置另一个空间。

## 健康逻辑

今日累计截至当前时间，不将未到时间的事件算入当天。趋势给出单位和日期；折线用于体重，柱状图用于进食、饮水与如厕次数。点击图上数据点、键盘Enter或日期选择均可查看数据。缺失日不连线，只有一条真实称重时不造历史曲线。

设备事件详情包含宠物、设备、时间及对应测量；修正宠物归属和备注后，从事件重新计算两个宠物的统计与趋势，保留原识别与修正时间。近期变化提示比较最近7个完整日与之前7天，查看同期生活数据和人工观察，不自动诊断。

## 相册逻辑

按拍摄日期倒序组织，默认年份分组，月份筛选进入月浏览。未知拍摄时间单独显示，不以上传时间替代。「往年同月」和「初到家时」只依据已有真实照片与到家月份，缺失时显示无记录。里程碑保留月份精度。

照片详情连续浏览当前筛选结果，展示拍摄日期、描述与标签。拍摄/上传信息折叠，编辑与分享自然衔接。新照片默认私密，公开案例资源的来源在统一说明中保留。

## 社区逻辑

漂流瓶以照片为主，反馈改变当前状态，下一只随机换宠物。广场高级筛选折叠，发布体验分享后清除限制筛选，保证看到刚分享的内容。无虚构在线人数、陌生人私聊、真实公开发布或远程审核。

同城先选择「今天去哪遛狗 / 附近的养宠生活 / 同城经验与求助」，再选择城市、区域与内容。体验地点不提供真实导航、报名或预约；出行前应核实。
