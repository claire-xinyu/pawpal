# PawPal｜一起长大

每一段成长，都有人一起见证。

面向年轻养宠者，尤其多宠家庭、共同照护家庭和独居养宠者。照片分散、健康记录易忘、多人照护缺少可见分工，以及社区过于围绕宠主私人关系，是本轮解决的具体问题。

产品以宠物档案为中心，连接记录、家庭照护与宠物内容分享，不提供陌生人恋爱匹配或私聊。第一版是可交互的公开产品案例，真实猫咪资料与有边界的演示内容并用，没有商业后台。

|一级页面|用户要完成的事|
|---|---|
|我的家|看见宠物及家庭；查看性格、身体、相遇故事、相处边界；建档、快速上传、安排照护；查看真实本机活动|
|成长|按宠物、月份及标题/描述/标签搜索相册；浏览详情，编辑或删除；切换拍摄日期驱动的时间线；主动分享|
|健康|记录实测体重、疫苗、驱虫；CRUD与用户计划提醒；文本生活观察；创建和完成照护任务|
|发现|漂流瓶给予宠物善意；广场发布图文并筛选、收藏；同城探索地点/路线/经验/活动演示资源|

个人、家庭、演示成员、备份与隐私说明位于右上角。全局宠物选择跨页面保持，支持全部宠物。独自记录无需邀请家人。

## 三条完整路径

1. 切换耳朵/尾巴 → 查看独立档案 → 按宠物浏览相册 → 查看月份到家记录和拍摄日期时间线。
2. 添加实测体重或疫苗/驱虫 → 当前宠物健康总览更新 → 有足够实测数据才生成趋势，只有用户填写下次日期才生成提醒 → 自动进入时间线。
3. 选择相册照片 → 选择分享目的地 → 确认本机分享范围与内容 → 漂流瓶/广场出现分享 → 摸摸头、好可爱、喜欢、收藏或本机评论产生持久状态。

照护任务可指定宠物、演示负责人及计划日期。完成进入家庭活动和时间线；可撤销完成。举报/屏蔽隐藏内容，可从设置恢复；不声称真实审核。

## 数据真实性

家庭5人是主人提供的数量，具体成员名与身份为演示。耳朵、尾巴资料来自主人，性别、外貌与到家月份不虚构；年龄和当前体重为估算。体重无测量日期，没有历史疫苗、驱虫或体重种子记录。发现耳螨的月份事件仅描述主人提供的情况，治疗及恢复待确认。血统猜测不作为品种；两姐妹是家庭称呼，不宣称血缘。

相册10张经筛选真实照片，其中1张合照关联两猫。其余社区动物与同城资源明确为演示，不用虚假在线人数或地点可用性增强可信度。新录入是本机用户记录，界面不自动诊断。

## 记录与分享

公开案例图片和资料已随网站发布，不能被称作有权限保护的私有数据。新照片与健康记录只存当前浏览器，默认不进入分享池；手动确认后复制选定的照片和文字到本机社区演示池，健康档案不随分享。无账号、远程多人协作、真实公共留言或服务器审核。

## 状态与范围

有空相册、无实测、无提醒、无照护、无动态、搜索无结果、文件不可读、图片缺失、存储失败、保存中与成功反馈。危险删除确认；日期无效及存储失败保留表单输入。未知拍摄日期可留空，不用上传时间替代。
