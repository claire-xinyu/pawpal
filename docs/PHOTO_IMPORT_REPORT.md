# Apple Photos 只读导入报告

检查范围仅为「耳朵」「尾巴」两个相册。工具 osxphotos 0.77.2、Python 3.12.13、macOS ImageIO/sips 和 sharp；原件未编辑、移动或删除。Photos数据库记录的日期包含用户调整，未以文件创建时间替代。

两个相册共有24张相同UUID照片，合并后247张独立照片。可读取原件/编辑版共23张，其中1张属于两个相册；可用文件SHA-256未发现额外重复。仅对这23张制作本机私有审图副本，不下载全部iCloud原件。其余224张未处理图片，原件不可在本机读取；仍提取了指定相册的记录元数据。

选出10张独立公开照片，包括真实双猫合照1张；耳朵5张、尾巴6张的关联数包含这张合照。每只猫选了1张档案封面和4/5张其他重点生活照片。没有补造发现时照片或血缘关系。

成功生成30份WebP衍生资源（400、1000、1600像素边长上限），不放大原始低分辨率图片。宽高比保留。前端懒加载与srcset选择尺寸；详情大图为contain。公开资源不包含EXIF、GPS、XMP、IPTC、ICC或设备标识；公开模块不含原件路径、私人文件名、原始UUID或精确位置。

逐张查看了23张私有审图副本以及10張待公开大图。人物肖像、有人体局部或背景存在疑虑的图片未公开；待确认清单保存在被Git忽略的`.private/selected-review.json`。其他未选照片主要因相似构图、清晰度、背景或历史片段重复。未处理不代表照片不存在。

公开元数据仅含宠物关联、审查后的中性标题/描述/标签、Photos拍摄时间与时区、真实导入时间、尺寸和网站资源路径。仅使用概括城市深圳。Photos原始元数据和审图副本全部位于被Git忽略的`.private/`目录。

对所选源文件导入前后SHA-256一致。没有改写图库原件。公开网站的案例图片所有访问者可见；新增上传仍只保存在当前浏览器。图库访问可用，但未处理离线原件或后台iCloud下载。

日期范围以Photos元数据为准，不推断宠物精确生日。标题描述为开发时人工标注的可见画面，不冒充主人原始照片备注。参考：[osxphotos](https://github.com/RhetTbull/osxphotos)。
